# Практическая работа №9 — Django ORM

Продолжение проекта «Удобрения для цветов». Эта ветка сохраняет результаты предыдущих практических работ в корне репозитория.

В ПР9 реализованы модели Flower, Fertilizer и FertilizerFlower, связи между ними, миграции, перенос данных из SQLite ПР7, ORM-запросы для получения, фильтрации, поиска, сортировки и статистики, а также постраничный вывод.

Для запуска полного проекта в VS Code: `python -m pip install -r requirements.txt`, `python manage.py migrate`, `python db/import_sqlite_to_orm.py`, `python manage.py runserver`. Команды выполняются из корневой папки проекта после распаковки файлов.

Проверки запуска Django и миграций должны быть выполнены в установленном окружении. Отчёт и необходимые скриншоты оформляются отдельно.
