 Сервис учета удобрений для растений

 Назначение

Сервис предназначен для учета удобрений, которые используются при уходе за растениями.

Программа позволяет указать растение, удобрение и дозировку, после чего проверяет указанную дозировку и выводит информацию о применении удобрения.

 Целевая аудитория

Сервис предназначен для людей, которые выращивают комнатные и садовые растения и хотят учитывать используемые удобрения.

 Предметная область

Предметная область связана с уходом за растениями и использованием удобрений.

Пользователь может указать растение, удобрение и дозировку его применения. В дальнейшем информация может храниться в базе данных и использоваться для учета применений удобрений.

 Основные сущности

- растение
- удобрение
- применение
- дозировка

 Основные функции

- ввод информации о растении
- ввод информации об удобрении
- проверка дозировки удобрения
- вывод информации о применении удобрения

 План развития

На следующих этапах планируется:

- создание консольной программы с несколькими сценариями
- добавление функций для работы с данными
- создание классов растений и удобрений

- добавление возможности создания, изменения и удаления данных
