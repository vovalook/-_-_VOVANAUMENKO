# Сервис учёта удобрений для растений

Индивидуальный проект по дисциплине «Технологии разработки приложений на базе
фреймворков». Тема № 463. Практическая работа № 3.

## Назначение проекта

Программа помогает вести простой журнал применения жидких удобрений для
растений. Пользователь добавляет растения, добавляет удобрения с запасом в
миллилитрах, записывает применение, смотрит журнал, ищет записи и получает
статистику расхода.

В ПР3 проект из ПР2 был переведён на объектно-ориентированную модель. Раньше
основные данные хранились как словари. Теперь растения, удобрения и записи
журнала создаются как объекты классов.

## Что изменилось после ПР2

- Добавлен модуль `models.py`.
- Основные сущности представлены классами.
- Добавлен базовый класс `NamedEntity` для объектов с номером и названием.
- `Plant` и `Fertilizer` наследуются от `NamedEntity`.
- Для объектов реализованы `__init__`, `__str__`, методы работы с данными.
- Для загрузки из JSON используются `@classmethod`.
- Для проверки запаса удобрения используется `@staticmethod`.
- JSON остался форматом хранения, но при запуске словари превращаются в
  объекты, а при сохранении объекты снова превращаются в обычные данные.
- Тесты адаптированы под объектную модель.

## Основные классы

`NamedEntity` - общий родитель для объектов с номером и названием. В нём
хранятся `item_id` и `name`, а также есть метод `to_data()`.

`Plant` - растение, для которого ведётся учёт применения удобрений.

`Fertilizer` - удобрение. У объекта есть `stock_ml`, методы `spend()`,
`restore()` и `can_spend()`.

`Application` - запись журнала применения удобрения. В объекте хранится номер
записи, номер растения, номер удобрения, дозировка и дата.

## Структура проекта

- `main.py` - консольное меню и взаимодействие с пользователем.
- `models.py` - классы предметной области.
- `services.py` - операции с коллекциями объектов.
- `storage.py` - загрузка и сохранение JSON.
- `utils.py` - проверка ввода, чисел и дат.
- `data/database.json` - файл данных.
- `tests/test_services.py` - тесты логики сервиса.
- `tests/test_storage.py` - тесты чтения и записи JSON.
- `requirements-dev.txt` - зависимости для проверки.
- `.flake8` - настройки проверки стиля.

## Запуск

Откройте папку проекта в VS Code. Для запуска программы:

```powershell
.\venv\Scripts\python.exe main.py
```

Если виртуальное окружение ещё не создано:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\venv\Scripts\python.exe main.py
```

## Проверка

```powershell
.\venv\Scripts\python.exe -m pytest -q
.\venv\Scripts\python.exe -m flake8
```

В подготовленной версии проходят 16 тестов. Flake8 не выводит замечаний.
